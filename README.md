# Password Generator

A simple Java console-based application that generates strong and random passwords based on user-defined length.

## Features

- Generate random passwords of any length
- Includes:
  - Uppercase letters (A-Z)
  - Lowercase letters (a-z)
  - Numbers (0-9)
  - Special symbols (!@#$%^&*)
- Ensures at least one character from each category
- Randomly shuffles characters for better security
- User-friendly console interface

## Technologies Used

- Java
- OOP Concepts
- StringBuilder
- ArrayList
- Collections Framework
- Random Class

## How to Run

1. Open the project in Eclipse or any Java IDE.
2. Compile and run `PasswordGenerator.java`.
3. Enter the desired password length.
4. The program will generate a secure random password.

## Sample Output

```
Enter password length: 10
Generated Password: A@7kP2#mQx
```
